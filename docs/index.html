Open-source starter

Cut your own calls into captioned clips.

A small pipeline: transcribe the recording, pick the moments by reading, cut at word boundaries, and render captions that land on every word.

Get the starter How it works

A 7-second synthetic test clip: two moments spliced, captions lit word by word.

Four steps

  1. TranscribeWhisper, on your laptop. Word-level timestamps, free.
  2. PickRead the transcript, note the in and out. Choose clips by reading.
  3. CutCuts snap to the gap between words. Captions travel with the cut.
  4. RenderRemotion draws the captions over your recording, ready to post.

Why the captions stay in sync

No mid-word cuts

If a cut point lands inside a spoken word, the tool moves it just outside that word and tells you. No clipped syllables, no stutter at the splice.

Seams handled

A word belongs to the chunk holding its midpoint, and every splice starts a fresh caption line. Nothing lights up and never turns off.

Try it

git clone <repo> && cd call-clip-starter
pip install -r requirements.txt
(cd remotion && npm install)

python3 transcribe.py my-call.mp4
python3 cut.py plan.json
cd remotion && npm run render

Needs Python 3.9+, Node 18+ and ffmpeg. Tested on macOS.

Not ready to code?

Descript (edit the transcript like a document) and CapCut (auto-captions with word-by-word styling) get you most of the way with no setup. This repo pays off once you cut the same kind of clip again and again.

MIT licensed. Whisper can mishear names and jargon, so skim the captions before you post.
